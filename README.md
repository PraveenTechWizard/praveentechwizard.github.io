# Portfolio — J. Praveen Kumar

Personal portfolio of a Unity developer (C#). It shows my games, gameplay videos, small mechanic prototypes, skills and contact details.

Built by hand with plain HTML, CSS and JavaScript. No frameworks and no build step.

## Edit the content
Open `js/data.js`. Your links, projects, mechanics and skills are all there.

## Folders
- `index.html` — the page
- `css/style.css` — colours and layout
- `js/data.js` — all the text content
- `js/main.js` — builds the page from the data
- `assets/` — screenshots and gameplay videos
- `resume/` — resume PDF and Word file
